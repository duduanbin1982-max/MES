# 项目排程看板（UI 说明）

> 入口：`项目排程 /schedule`  
> 2026-11-04 改版：一屏看清「本周计划 / 完成率 / 进行中 / 异常」，异常可直接筛选、可批量重排程、可撤销。

## 1. 页面结构

```
项目排程
├─ 顶部：更新时间 · 刷新 · 批次记录 · 批量重排程
├─ Tab「本周任务」
│   ├─ 4 张 KPI：本周计划 / 完成率 / 进行中 / 异常（可点击筛选）
│   ├─ 筛选栏：周次（上一周/本周/下一周）· 项目 · 关键词 · 状态 · 只看异常 · 清除
│   └─ 按项目分组：项目头（超期/受阻/未排程徽标 + 完成率进度条）+ 工序表
└─ Tab「项目里程碑」
    ├─ 项目选择
    ├─ 里程碑表：状态 / 计划与实际时间 / 进度条 / 完成·开始
    └─ 空状态给「去工艺树排程」入口
```

## 2. 异常口径（与仪表盘延误口径对齐）

| 判定 | 条件 | 展示 |
|---|---|---|
| **超期** | `planned_end < 现在` 且未完成/未取消 | 行淡红底 + 计划时间标红 + 「超 N 天」标签 |
| **受阻** | `status = blocked` | 「受阻」标签 |
| **未排程** | `planned_start` 与 `planned_end` 都为空 | 计划时间显示「未排程」 |

「异常」KPI = 超期 + 受阻 + 未排程；点击该卡片 = 开启「只看异常」，再点取消。

> 说明：`/api/schedule/weekly` 会把所有未完成节点（含未来计划、未排程）都返回，
> 所以 KPI 的「本周计划」是**前端按周区间过滤**后的数量，副标题给出「未完成合计」，避免把 87 条待办误读成"本周任务 87"。

## 3. 操作

| 位置 | 操作 |
|---|---|
| 行主按钮 | 待开始 → 开始；进行中/受阻/暂停 → 完成 |
| 行「更多」 | 暂停（`paused`）、标记受阻（`blocked`）、回到待开始（`pending`）、分配 / 改期 |
| 行点击 | 打开「分配 / 调整工序」弹窗（负责人、计划时间、工位） |
| 顶部「批次记录」 | 抽屉列出重排批次，可整批撤销（撤销会跳过被手工改过的节点） |
| 顶部「批量重排程」 | 对齐到日期 / 顺延天数 → 预览 → 应用 |

> 2026-11-04 修正：旧版「暂停」实际上把状态写成 `pending`，现在是 `paused`；
> 状态文案也补齐了 `ready`/`paused`/`cancelled`，不再出现英文原值。

## 4. 展示细节

- 状态标签色：待开始=灰、已就绪=蓝、进行中=橙、暂停=灰、受阻=红、完成=绿；
- 计划时间紧凑显示（`11-10 ~ 11-11 08:00`），悬停显示完整时间；
- 项目头显示完成率进度条与「完成 x / y」；
- 空状态分两种：有筛选 → 「清除筛选」；无筛选 → 「去批量重排程」；
- 窄屏（<1200px）KPI 变 2 列，<768px 变 1 列，项目头改为上下排列。
