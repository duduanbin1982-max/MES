## 二、逐步操作

### 第 0 步：认识驾驶舱（2 分钟）

1. 打开 `https://192.168.1.73/dashboard`
2. 找到「全流程健康检查」卡片 → 项目下拉选 **TBM-DEMO-001（28.1 分）**
3. 观察 8 行：项目与里程碑 ✅、设计与 BOM 🟡、其余 ⬜
4. **记住 28.1 这个数**，后面每步回来对比

---

### 第 1 步：维护项目信息（3 分钟）

**页面**：`/instances` → 点进 `TBM-DEMO-001` → 右上角 **「编辑项目信息」**

做三件事：
1. 拖动「进度」滑块到 `5%`（或直接在右侧输入框填 5）
2. 客户联系人填 `培训组 / 13800000000`
3. 现场位置填 `厂内培训区 1 号工位`
4. 点「保存」

**成功标志**：弹窗关闭并提示"已保存项目信息"；详情页「合同与编码」里能看到联系人与现场位置。

> 该按钮在项目冻结/归档后会禁用（基线不可改）。后端接口：`PUT /api/equipment_instances/:id`

---

### 第 2 步：建 BOM 结构（5 分钟）

**页面**：`/bom`（项目结构 / BOM 树）

1. 顶部右上角「选择项目装备」→ 选 **TBM-DEMO-001**
2. 在「项目结构树」里**点一下根节点**（`0 · TBM-DEMO-001`，这是创建实例时自动生成的）
3. 点 **「+ 新增子部件」**，在弹窗里填：

| 字段 | 钢板行 | 螺栓行 | 密封行 |
|---|---|---|---|
| 层级 | 1（自动） | 2（先选中钢板行再加子件） | 2（同左，选中钢板行） |
| 父节点 | 根节点（自动） | 钢板行 | 钢板行 |
| 物料 | 搜索 `M-ST-Q345-50` | 搜索 `M-BOLT-M20-10` | 搜索 `M-SEAL-MAIN` |
| 数量 | `600` | `24` | `1` |
| 单位 | `千克` | `件` | `套` |
| 分类（必填） | 原材料 | 标准紧固件 | 外购成品 |
| 节点类型 | raw_material | standard | purchased |
| 图号/型号 | 可选 | 可选 | 可选 |

4. 每行点「保存」。三行加完，树里应显示 **根节点 + 3 个子件**；顶部统计卡变「1 级 1 / 2 级 2」。

> 为什么钢板单位是「千克」：主数据里 `M-ST-Q345-50` 的基准单位就是 kg，BOM 单位要与之一致（否则后续领料/量差会对不上）。  
> 如果三行都想直接挂在根节点下（都是 1 级），也可以 —— 不影响后续步骤。

**成功标志**：BOM 页显示 4 行（根 + 3），"挂物料"列由 0 变 3。

> 这一步健康分**不会变**（还是 28.1）：BOM 环节要求"物料 + 实装批次"都有，批次要到第 4 步才挂。

| 批次号 | `DEMO-BOLT-2611A` |

| 到货日期 | `2026-11-03` |
| 数量 | `100` |
| 单位 | 件 |
| 质检状态 | `pending`（待检） |

> 另外两个物料的批次系统里已有：`M-ST-Q345-50` → `BG-Q34550-2612A`、`M-SEAL-MAIN` → `SKF-SEAL-2610-01`。

**成功标志**：批次列表里出现 `DEMO-BOLT-2611A`。

### 第 6 步：跑一次排程（5 分钟）

**页面**：`/multi-schedule`

1. 起始日期填 `2026-11-01`，天数 `30`
2. 看工位负荷热力图：焊接工位 1 在 11/05–11/10 应有负荷
3. 点一个有负荷的格子 → 看当日任务 → 试着用「拖拽/选择」把任务改派到镗孔工位，再改回来
4. 再看 `/gantt`（单项目甘特）确认关键路径

**成功标志**：热力图有 2 个工位出现负荷；能完成一次改派并看到提示。

## 三、每步卡住怎么办

| 卡住的现象 | 处理 |
|---|---|
| 页面找不到"新增"按钮 | 换列表页的工具栏；或告诉我，我用接口帮你补 |
| 下拉里没有物料/工位/用户 | 说明主数据没维护，先在 `/mdm`、`/workstation-resources` 建 |
| 批次下拉是空的 | BOM 行上一级先选物料，再选批次 |
| 保存报 400 | 看提示哪个字段必填；中文标题/文件名已支持 |
| 分数没变 | 刷新页面；确认改的是 **TBM-DEMO-001**（实例 ID 8） |
| 上传图纸后文档环节还是 0 | 检查「关联设备」是否选了 TBM-DEMO-001 |
