## 4. 本轮已落地整改

### 后端 `services/process/params.js`

1. **新增 `GET /api/process_nodes/:id/params/specs`**：前端读取当前 LSL/USL/target/unit；
2. **规格物理范围校验**：按 `PARAM_LIMITS` 限制 LSL/USL；
3. **记录人防伪**：非本人 `recorded_by` 需要管理员，否则 403；
4. **空白记录拦截**：参数值/custom_json/备注全空 → 400；
5. **节点存在性**：参数列表、趋势、规格 GET 统一 404；
6. **偏差扫描覆盖**：从“前 200 节点”改为“有规格的所有节点”；
7. **规格查找一致**：按 `recorded_at DESC, id DESC` 取 50 条，与 SPC 一致。

### 前端 `ProcessParams.vue`

1. **修复节点加载（P0）**：兼容 `{flat}` 响应，页面终于能选节点；
2. **节点下拉**：`#id 名称 (类型)` + `filterable`；
3. **新增“规格设置”弹窗**：6 个参数的 LSL/USL/目标/单位维护；
4. **规格判定**：
   - 参数单元格按 LSL/USL 标红；
   - 新增“判定”列显示超差参数；
   - 趋势图增加 LSL/USL 标线；
5. **状态修正**：切换节点/实例清空参数、规格、SPC 结果；
6. **温度阈值**：移除硬编码 300°C，按规格判定。

   - 优先覆盖关键工序：焊接、机加工、装配、调试、检验；

   - 需确认采集器是否停采、设备是否离线、是否只保留演示数据。
3. **配置规格**
   - 仅 3 个节点有规格；
   - 在 `/process-params` → 选节点 → 规格设置，补齐 LSL/USL/target/unit。
4. **清理历史 SPC 报警**

5. **记录人真实化**

## 7. 遗留风险

1. 参数列表无分页/时间范围，单节点已 351 条，长期采集会变慢；
2. 趋势图异常被静默吞掉，无用户提示；
3. `/spc/analyze` 与页面权限模型不一致（quality vs process）；
4. `monitor` / `deviations` 后端有接口，前端未接入总览页；
5. 规格弹窗是数值输入，未接“按工序模板默认规格”自动带出；
6. 空白记录已拦截，但历史无效数据未清理；
7. 规格与 SPC 读取逻辑仍分散在 `params.js` 与 `spcService.js`，建议抽公共读模型。
