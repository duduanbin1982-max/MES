## 4. 本轮修复

### 4.1 全口径偏差

新增 `full_totals`：

- `standard_cost` = 材料标准 + 人工标准 + 关键件标准；
- `actual_cost` = 材料实际（有领料按实际，未领料用标准占位） + 人工实际（台账优先） + 关键件实际 + 其他台账成本；
- `total_variance` = 实际 − 标准；
- 分项：`material_standard/actual`、`labor_standard/actual`、`key_component_standard/actual`、`other_costs`。

新增 `key_components`：

- 11 项关键件，标准 33,848,000 元、实际 34,448,000 元；
- 价差 **+600,000 元**；
- 关键件单价按万元/件 ×10000 归一化。

`ledger` 修正：

- `total`：台账已过账合计（24,500）；
- `actual_total_including_other`：全口径实际（36,095,904.80）；
- 人工按台账优先，避免与工时推算重复。

### 4.2 材料缺失处理

- 有领料记录：按实际用量/实际价计算；
- 无领料记录：标准成本作为实际占位，不产生“节约”；
- `full_totals.material_actual_computed` / `material_unavailable_standard_proxy` 分列；
- 页面仍显示 `data_gaps` 与 `confidence=partial`。

### 4.3 前端

- 偏差页显示项目选择器；
- “预算基线”使用全口径标准成本；
- “实际归集”/“偏差”使用全口径字段；
- 新增“全口径标准/实际/差异”描述；
- 新增关键件价差标签；
- 台账“已过账合计”和“全口径实际（含关键件）”分开展示。

## 6. 仍需注意

1. **关键件只有价差，没有量差**：缺少实际采购/领用数量，量差暂不可算。
2. **材料实际价**仍取 `materials.actual_unit_price`，不是采购订单/台账最终价；台账 cross_check 只能提示差异。
3. **报工覆盖仅 0.18%**，人工效率差不进入合计；页面标记 `confidence=partial`，补齐报工后重算。
4. **未领料物料**用标准成本占位，是为了不误读为节约；真实差异需补齐领料记录后重算。
5. **成本归集页与偏差页口径**：成本归集页顶部是 cost_rollup 全口径，偏差页使用 `variance.full_totals`；两者材料实际价/台账优先级略有差异，需财务确认统一口径。
6. 关键件万元/件单位以迁移 014 注释为准；若业务录入口径改变，需同步 `units.js`。
7. 项目选择器默认第一个实例（当前为演练机），进入页面后应手动选目标项目。
