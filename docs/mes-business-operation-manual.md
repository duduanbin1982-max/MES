# TBM-MES 业务流程清查与操作手册

> 适用系统：`https://192.168.1.73`  
> 适用版本：TBM-MES v2.3  
> 清查范围：前端菜单、路由入口、服务注册、核心业务 API、现有业务文档  
> 更新时间：2026-07-07

## 1. 清查结论

当前 MES 已经不是单一“生产看板”，而是围绕 **TBM / 非标装备项目交付** 建立的业务闭环系统。主线可以概括为：

```text
用户/权限 → 主数据 → 装备实例 → BOM → 图纸/文档 → 工艺路线
→ 工单/排程 → 齐套/采购/领料 → 车间报工 → 质检/NCR/CAPA
→ 成本归集 → 客户验收 → 追溯/售后/维保
```

系统当前左侧菜单已经按 10 大业务域归类：

| 一级菜单 | 解决的问题 | 核心入口 |
|---|---|---|
| 首页驾驶舱 | 管理层一屏看交付、风险、OEE、报表 | `/dashboard`, `/delivery`, `/reports`, `/oee` |
| 项目与装备 | 这台 TBM 到哪一步了 | `/instances`, `/schedule`, `/gantt`, `/tbm-advanced` |
| 设计与BOM | 工程数据、BOM、图纸、ECO、工艺 | `/bom`, `/documents`, `/eco`, `/process-tree` |
| 生产执行 | 工单、派工、报工、车间扫码 | `/work-orders`, `/process-hours`, `/shopfloor` |
| 采购与库存 | 物料主数据、库存、采购、齐套、跟催 | `/materials`, `/purchase`, `/kit-closure` |
| 质量与追溯 | 检验、NCR/CAPA、来料/过程/出厂、追溯 | `/quality`, `/spc`, `/trace` |
| 设备与维护 | 设备台账、点检、维保、备件、IoT、数字孪生 | `/resources`, `/field-service`, `/iot`, `/digital-twin` |
| 成本与经营 | 材料、人工、外协、折旧、成本偏差 | `/cost`, `/reports`, `/delivery` |
| 异常与协同 | 缺料、采购、质量、主数据、ANDON 待办 | `/exceptions`, `/andon` |
| 系统管理 | 用户、角色、权限、工位、资质、编码、审计 | `/users`, `/settings`, `/audit`, `/mdm` |

## 2. 登录与角色默认首页

### 2.1 登录

1. 打开 `https://192.168.1.73/login`。
2. 输入账号密码。
3. 登录后系统根据角色进入默认工作区。

### 2.2 角色化默认入口

| 角色 | 默认入口 | 说明 |
|---|---|---|
| `admin` / 管理员 | `/dashboard` | 看全局驾驶舱与全部模块 |
| `warehouse` / 仓库员 | `/shopfloor?tab=pick` | 默认进入领料/退料工作台 |
| `qc` / 质检员 | `/shopfloor?tab=qc` | 默认进入质检录入 |
| `worker` / 工人 | `/shopfloor?tab=scan` | 默认进入扫码报工 |
| `welder` / 焊工 | `/shopfloor?tab=scan` | 默认进入扫码报工 |

注意：前端菜单和后端 API 都有 RBAC 权限控制。仓库角色只能看到库存、领退料、物料、工单、文档等相关入口。

## 3. 空白系统第一天操作顺序

空白 MES 不建议直接建工单。正确顺序是先把“人、机、料、法、图、项目骨架”建好。

### 第 1 步：建用户、角色、权限

入口：`系统管理 → 用户管理 / 角色与权限 / 角色组`  
URL：`/users?tab=users`, `/users?tab=matrix`, `/users?tab=groups`

操作：

1. 创建管理员、生产主管、计划员、仓库员、质检员、工人、采购员、工程师。
2. 给角色分配权限，例如：
   - 生产主管：工单、排程、资源、报表、异常。
   - 仓库员：物料、库存、领料、退料、齐套。
   - 质检员：质检、NCR、CAPA、追溯。
   - 工程师：BOM、图纸、ECO、工艺树。
3. 使用角色组管理同类岗位，避免每个用户单独配权限。

验收标准：

- 至少有 `admin`、`warehouse`、`qc`、`worker` 等基础角色。
- 普通用户不能看到不属于自己的菜单。
- `/audit` 可以看到用户、角色、关键业务变更记录。

### 第 2 步：建工位、人员、供应商

入口：

- `系统管理 → 工位/资源配置`：`/resources`
- `系统管理 → 人员资质`：`/labor`
- `采购与库存 → 供应商管理`：`/purchase?tab=suppliers`

操作：

1. 建工位：装配工位、焊接工位、机加工位、检验工位。
2. 建人员资源：录入人员所在工位、状态、技能。
3. 建人员资质：焊工证、检验证、特种作业证、培训记录。
4. 建供应商并分类：
   - 关键件供应商
   - 外协供应商
   - 标准件供应商
   - 原材料供应商
   - 服务类供应商

验收标准：

- 生产排程能选择工位。
- 工序能绑定标准工时、工位、技能要求。
- 采购管理能按供应商分类筛选。
- 劳动力管理能提示资质过期或不匹配。

### 第 3 步：建物料主数据

入口：`采购与库存 → 物料中心`  
URL：`/materials?tab=materials`

操作：

1. 新增或导入物料主数据。
2. 补齐物料编码、名称、规格、单位、分类、安全库存、再订货点。
3. 使用 Excel/CSV 导入时，先走“校验”，通过后再提交。
4. 处理“一物一码”问题：
   - 同物同码
   - 异物异码
   - 不允许重复编码、模糊名称、缺单位

常用页面：

- `物料中心`：维护“是什么”。
- `库存清单`：查看“有多少、在哪”。
- `库存预警`：查看低于安全库存、呆滞库存、缺料。

验收标准：

- 物料编码完整。
- 无重复编码。
- 关键物料设置安全库存和长交期。

### 第 4 步：建装备实例

入口：`项目与装备 → 装备实例`  
URL：`/instances`

操作：

1. 点击“创建向导”。
2. 填写项目号、合同号、序列号、客户、年份、设备类型、型号。
3. 系统应同时生成：
   - 合同信息
   - 默认里程碑
   - 生命周期阶段
   - BOM 空壳
   - 文档目录
4. 设置生命周期：
   - 设计中
   - 采购中
   - 制造中
   - 总装中
   - 调试中
   - 验收中
   - 交付
   - 运维

验收标准：

- 实例编码符合规则。
- 项目交付看板能看到该实例。
- 实例详情能进入 BOM、图纸、采购、齐套、工单、质检、成本、风险。

### 第 5 步：导入或维护 BOM

入口：`设计与BOM → BOM 管理`  
URL：`/bom`

操作：

1. 选择装备实例。
2. 建立 4 级 BOM：
   - 0 级：整机/总装
   - 1 级：部件/模组
   - 2 级：零件/外购件
   - 3 级：原材料/毛坯
3. 逐项补齐字段：
   - 层级
   - 物料编码
   - 名称
   - 图号/型号
   - 数量
   - 单位
   - 分类
   - 材质
   - 表面处理
   - 推荐品牌
   - 版本
   - 备注
4. 使用 BOM 校验：
   - 根节点唯一
   - 层级正确
   - 物料存在
   - 虚项不能作为叶子
   - 自制件有材质和表面处理
5. 使用业务视图：
   - 采购视图
   - 装配视图
   - 毛坯视图
   - 成本视图
   - 工艺完整性视图
   - 风险视图

验收标准：

- 至少有 0、1、2 级。
- BOM 通过结构校验。
- 风险部件能钻取采购单、到货计划、责任人。

### 第 6 步：绑定图纸/文档

入口：`设计与BOM → 文档/图纸`  
URL：`/documents`

操作：

1. 上传图纸、SOP、工艺文件、检验标准。
2. 绑定装备实例、BOM 节点、图号/版本。
3. 签发文档。
4. 现场人员在车间端查看并签收。
5. 如果发生 ECO，旧版本归档，新版本重新签发。

验收标准：

- 现场只能看到最新版有效文档。
- 有签收记录。
- 图纸和 BOM 节点可追溯。

### 第 7 步：建工艺路线

入口：

- `设计与BOM → 工艺树`：`/process-tree`
- `设计与BOM → 工艺参数`：`/process-params`
- `生产执行 → 工时与报工`：`/process-hours`

操作：

1. 按部件生成或维护工艺树。
2. 每个工序补齐：
   - 工序名称
   - 前后依赖
   - 标准工时
   - 工位
   - 人员/技能要求
   - 关键工艺参数
3. 维护工序依赖：
   - FS：完成后开始
   - SS：同步开始
   - FF：同步完成
4. 用 Gantt 或项目排程检查路径是否合理。

验收标准：

- 工序能排程。
- 工序能报工。
- 工序能看标准工时、实际工时、进度。

### 第 8 步：生成工单和排程

入口：

- `生产执行 → 工单管理`：`/work-orders?tab=list`
- `生产执行 → 生产单元派工`：`/work-orders?tab=dispatch`
- `项目与装备 → 项目排程`：`/schedule`
- `项目与装备 → Gantt`：`/gantt`

操作：

1. 创建工单，关联装备实例、BOM 节点或工艺节点。
2. 下发工单到班组/工位/人员。
3. 做排程 dry-run，确认无冲突后正式排程。
4. 查看 Gantt，检查关键路径和瓶颈工位。

验收标准：

- 工单状态正常流转。
- 工单能做齐套检查。
- 工单能扫码报工和质检。

## 4. 项目交付主线操作

### 4.1 生产主管每天第一步

入口：`首页驾驶舱 → 仪表盘`  
URL：`/dashboard`

看 5 件事：

1. 项目总览：当前有多少装备实例、工单、关键件。
2. 风险待办：延误、ECO、现场服务、长交期关键件。
3. OEE：哪些工位忙、哪些工位空闲。
4. 现场实时状态：正在加工的工单和工序。
5. 长交期关键件：是否影响当前项目。

如果发现风险，进入：

- `/delivery` 看项目交付卡片。
- `/exceptions` 看异常中心。
- `/purchase?tab=followup` 看采购跟催。
- `/quality?tab=ncr` 看质量异常。

### 4.2 项目经理看交付

入口：`首页驾驶舱 → 项目交付看板`  
URL：`/delivery`

操作：

1. 选择 TBM 实例。
2. 查看合同/项目 → BOM → 图纸 → 采购 → 齐套 → 工单 → 报工 → 质检 → 成本 → 验收。
3. 钻取风险：
   - 缺料风险
   - NCR 风险
   - 成本偏差
   - 延误风险
   - 主数据异常
4. 根据责任人推进关闭。

### 4.3 工程师处理设计变更

入口：

- `设计与BOM → BOM 管理`：`/bom`
- `设计与BOM → 文档/图纸`：`/documents`
- `设计与BOM → 设计变更(ECO)`：`/eco`

操作：

1. 在 ECO 中创建变更。
2. 评估影响：
   - BOM 节点
   - 图纸版本
   - 采购单
   - 库存
   - 工单
   - 成本
3. 修改 BOM 版本。
4. 重新签发图纸。
5. 将影响项推送到异常中心或工作流。

### 4.4 采购员处理缺料和跟催

入口：

- `采购与库存 → 采购管理`：`/purchase?tab=orders`
- `采购与库存 → 采购跟催`：`/purchase?tab=followup`
- `采购与库存 → 齐套/缺料闭环`：`/kit-closure`

操作：

1. 根据齐套检查生成缺料清单。
2. 从 BOM 风险部件一键生成采购催办。
3. 分派缺料责任人。
4. 回写预计到货日期 ETA。
5. 跟催状态变化：
   - 已到货/已关闭 → 缺料关闭、BOM 风险消警、异常中心归档。
   - 已取消 → 缺料重开/改派/重新进入异常中心。
   - 重新发起 → 从异常中心回流到采购跟催。

### 4.5 仓库员领料/退料

入口：`生产执行 → 车间工作台` 或 `采购与库存 → 齐套/缺料闭环`  
URL：`/shopfloor?tab=pick`, `/kit-closure`

操作：

1. 选择工单。
2. 查看 pick-list。
3. 按 BOM 和批次扫码领料。
4. 库存自动扣减并记录物料批次。
5. 余料退库。
6. 报废或差异走异常中心。

注意：

- 仓库员账号默认进入领料页面。
- 仓库员不应直接操作设计、成本、用户权限等模块。

### 4.6 工人扫码报工

入口：`生产执行 → 车间工作台 → 扫码报工`  
URL：`/shopfloor?tab=scan`

操作：

1. 扫工单码或工序码。
2. 查看当前工序、图纸、标准工时、注意事项。
3. 开始/完成工序。
4. 填写实际工时、数量、异常说明。
5. 如遇停工、缺料、设备故障，触发 ANDON 或异常上报。

### 4.7 质检员处理质量闭环

入口：`质量与追溯 → 质检管理`  
URL：`/quality?tab=inspections`

操作：

1. 选择检验类型：
   - 来料检验
   - 过程检验
   - 出厂检验
2. 填写检验结果。
3. 发现不合格时创建 NCR。
4. NCR 处置：
   - 返工
   - 返修
   - 让步接收
   - 报废
   - 退货
5. 创建 CAPA。
6. 复检。
7. 关闭 NCR。

验收标准：

- NCR 进入异常中心。
- CAPA 有责任人和期限。
- 关闭后能追溯到供应商、批次、BOM、工单、项目。

### 4.8 成本会计/项目经理看成本

入口：`成本与经营 → 成本归集`  
URL：`/cost`

成本来源：

| 成本类型 | 来源 |
|---|---|
| 材料成本 | BOM、物料、采购合同价 |
| 人工成本 | 标准工时、实际报工 |
| 外协成本 | 外协采购/供应商协同 |
| 折旧成本 | 设备/资源折旧配置 |
| 返工成本 | NCR/CAPA、返工报工 |
| 质量损失 | 报废、退货、让步、返修 |

重点看：

- 采购估价 vs 实际合同价。
- 项目成本偏差。
- 部件/BOM 节点成本。
- 合同金额与实际成本差额。

### 4.9 设备维护和售后

入口：`设备与维护 → 现场服务 / 维保计划 / 备件库`  
URL：`/field-service`

操作：

1. 建维保计划。
2. 执行点检/TPM。
3. 记录故障。
4. 消耗备件。
5. 更新备件库存。
6. 形成售后服务记录。
7. 将典型故障沉淀到故障知识库。

## 5. 异常中心闭环

入口：`异常与协同 → 异常中心`  
URL：`/exceptions`

异常中心是跨部门问题统一入口。当前应纳入：

| 异常类型 | 来源 | 责任部门 |
|---|---|---|
| 缺料异常 | 齐套检查、库存预警、BOM 风险 | 仓库/采购 |
| 采购延期 | 采购跟催、ETA 逾期 | 采购 |
| 质量 NCR | 质检管理 | 质量/生产/供应商 |
| 工单延期 | 排程、Gantt、延误预警 | 生产 |
| 图纸未签收 | 文档/图纸 | 工程/车间 |
| 资质过期 | 劳动力管理 | 生产/HR |
| 主数据异常 | 主数据治理 | 数据管理员 |
| 设备故障 | ANDON、设备维护 | 设备/维修 |

标准处理动作：

1. 接收异常。
2. 指派责任人。
3. 填写原因。
4. 制定措施。
5. 回写业务对象状态。
6. 关闭异常。
7. 自动从看板风险中消警。

## 6. 常用角色操作速查

### 6.1 生产主管

每天：

1. `/dashboard` 看首页驾驶舱。
2. `/delivery` 看每台 TBM 卡在哪。
3. `/exceptions` 处理红色风险。
4. `/schedule` 和 `/gantt` 调整排程。
5. `/work-orders?tab=dispatch` 派工。
6. `/process-hours` 看工时与报工偏差。
7. `/quality?tab=ncr` 跟踪质量问题。

### 6.2 计划员

1. `/instances` 确认项目实例。
2. `/process-tree` 确认工艺树。
3. `/work-orders` 建工单。
4. `/schedule` 做排程。
5. `/gantt` 看冲突和关键路径。
6. `/kit-closure` 检查齐套。

### 6.3 工程师 / 工艺员

1. `/bom` 维护 BOM。
2. `/documents` 上传和签发图纸。
3. `/eco` 管理设计变更。
4. `/process-tree` 建工艺路线。
5. `/process-params` 维护关键参数。
6. `/spc` 看过程能力。

### 6.4 采购员

1. `/purchase?tab=orders` 管采购单。
2. `/purchase?tab=followup` 管跟催。
3. `/purchase?tab=suppliers` 管供应商。
4. `/kit-closure` 看缺料。
5. `/exceptions?type=purchase_delay` 处理采购异常。

### 6.5 仓库员

1. `/shopfloor?tab=pick` 领料/退料。
2. `/materials?tab=inv` 看库存。
3. `/material-alerts` 看库存预警。
4. `/kit-closure` 看齐套/缺料。
5. `/documents` 查图纸/SOP。

### 6.6 质检员

1. `/quality?tab=inspections` 做检验。
2. `/quality?tab=ncr` 处理 NCR。
3. `/quality?tab=inspections&type=incoming` 做来料检验。
4. `/quality?tab=inspections&type=in_process` 做过程检验。
5. `/quality?tab=inspections&type=final` 做出厂检验。
6. `/trace` 做追溯。

### 6.7 维修/售后

## 7. 数据质量红线

以下问题会直接影响 MES 后续效果：

1. 物料编码混乱：导致库存、采购、成本全部不准。
2. BOM 不按层级：导致齐套、领料、采购、装配全部失效。
3. 图纸版本不签发：现场可能拿错图纸。
4. 工艺路线无标准工时：排程和成本无法可信。
5. 工单不扫码报工：进度和人工成本失真。
6. 采购 ETA 不回写：项目交付看板无法判断风险。
7. NCR 不闭环：质量问题无法追溯和复盘。
8. 异常中心只开不关：看板会长期红灯，失去管理价值。

## 8. 故障排查速查

| 现象 | 常见原因 | 处理 |
|---|---|---|
| 登录后跳不进去 | token 过期、角色默认页受限 | 退出重新登录；检查角色和权限 |
| 页面提示 401 | 未登录或 token 无效 | 重新登录 |
| 页面提示 403 | 角色无权限 | 到 `/users` 检查权限 |
| 页面提示 404 | 前端调用了未注册 API 或旧静态资源 | 刷新缓存；确认后端已重启 |
| 页面提示 500 | 后端业务异常或数据结构不完整 | 看 `logs/server.log`，定位接口 |
| 左侧菜单少 | 当前角色权限过滤 | 用 admin 验证是否权限问题 |
| 数据为空 | 初始化数据未建完 | 先走 `/setup` 初始化向导 |
| 齐套不准 | BOM/库存/物料编码不完整 | 回到物料中心和 BOM 校验 |

## 9. 推荐上线使用节奏

### 第 1 周：让系统“能跑”

1. 用户/权限。

3. 物料主数据。
4. 装备实例。
5. BOM 0/1/2 级。

7. 工艺树和标准工时。

1. 项目交付看板。
2. 成本归集。

5. 追溯链路。
6. 维保/备件/现场服务。

## 10. 当前模块成熟度判断

| 模块 | 当前判断 | 使用建议 |
