# 一步到位启用 factory-mes 反代配置

请在 .73 上手动复制粘贴整段（一次 sudo 就够）：

```bash
sudo cp /home/dubin/factory-mes/nginx/factory-mes.conf /etc/nginx/sites-available/factory-mes && \
sudo ln -sf /etc/nginx/sites-available/factory-mes /etc/nginx/sites-enabled/factory-mes && \
sudo rm -f /etc/nginx/sites-enabled/default && \
sudo nginx -t && \
sudo systemctl restart nginx && \
echo "===验证===" && \
ss -tlnp | grep -E ":80|:443|:3890" && \
curl -sk https://localhost/api/health
```

**预期输出：**
- `nginx -t` 显示 `syntax is ok / test is successful`
- 端口有 80 + 443 + 127.0.0.1:3890（**不再有 0.0.0.0:3890**）
- `curl https://localhost/api/health` 返回 `{"status":"ok","service":"tbm-mes",...}`
